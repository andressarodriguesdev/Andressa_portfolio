## 💡 Sobre o Projeto

Este portfólio foi construído utilizando:

- **React.js** (v18.3.1)
- **TailwindCSS** (v3.4.11)
- **TypeScript**
- **Vite** (v5.4.1)
- **React Router Dom**
- **React Hook Form**
- **Axios**
- **React Query**
- **Dark Mode** com alternância personalizada
- **Deploy contínuo via Netlify**
- **Chatbot inteligente "Laura" integrado com Jamie, para respostas contextuais**

## 🧠 Destaques

- Tema claro/escuro com botão de alternância fácil de usar;
- Seção de projetos com cards interativos e links diretos;
- Chatbot Laura integrado, para interação personalizada;
- Contato com formulário funcional e links para redes sociais;
- Responsividade mobile-first, para ótima experiência em todos dispositivos.
